# Python---Data-Structures---List-Dictionary-Set-Conditional-Statements

Python Data Structures & Conditional Statements Assignment

This repository contains Python programs demonstrating core data structure operations (Lists, Dictionaries, and Sets) and decision-making using conditional statements (if, elif, else).

Objective

To build a strong understanding of:

List creation, modification, and access operations

Dictionary creation and manipulation using key-value pairs

Set properties and operations like uniqueness, union, and intersection

Decision-making using conditional statements

Requirements

Python 3.x (no external libraries required)

Key Learnings

Lists are ordered, mutable, and allow duplicate values; they support indexing, slicing, and a wide range of modification methods.

Dictionaries store data as key-value pairs, allowing fast lookup, addition, and updates by key.

Sets are unordered collections of unique elements — duplicates are automatically removed, and elements cannot be accessed via an index because sets do not maintain a positional order.

Conditional statements (if/elif/else) allow a program to make decisions and execute different code paths based on given conditions.
